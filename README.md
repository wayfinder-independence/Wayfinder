# Wayfinder

Wayfinder is a personal, independent, open-source project to help neurodivergent people do more of everyday life on their own terms, with greater confidence and less need to ask others for help. It is not a Microsoft product, service, or sponsored initiative.

Status: Pre-MVP

## Schedule Reader v0

The first capability reads a weekly schedule from a Word document and turns it into structured JSON. The JSON keeps what the schedule says separate from what Wayfinder suggests, and leaves room for a guardian to confirm or correct both. See [docs/schedule-reader.md](docs/schedule-reader.md).
